# 日文漫畫翻譯 SOP

## 1. 目標與交付契約

- 輸入：一個日文漫畫 ZIP。
- 輸出：一個同名 ZIP，壓縮檔內只有依原順序命名的繁體中文漫畫圖片。
- 壓縮檔內禁止放入原圖、校正圖、設定檔、記錄、報告或工作資料夾。
- 原始日文 ZIP 不得覆寫或自動刪除。
- 翻譯過程可使用暫存工作區；成功交付後必須自動清除。

## 2. 固定環境（只建立一次）

- 所有 Python、套件、模型與快取固定放在 `E:\日文翻譯用資料_需配對網站`。
- 網站不使用系統 Python，只呼叫該資料夾內的獨立 Python 3.11。
- 將可用套件版本鎖定；未變更環境時，不重新安裝或掃描依賴。
- 模型下載完成後寫入「已安裝模型清單」；下次僅驗證檔案是否存在與大小是否合理。
- 網路只用於首次模型下載；完整模型必須可離線重複使用。

## 3. 每本漫畫的四道關卡

### 關卡 A：輸入驗證（不啟動 AI）

1. 檢查 ZIP 能開啟。
2. 只讀取圖片清單，記錄原頁數、擴充名、尺寸與自然排序。
3. 排除非圖片檔和隱藏檔。
4. 建立本次唯一暫存目錄，禁止覆寫其他任務。

失敗條件：ZIP 破損、圖片為 0、檔名無法建立穩定順序。失敗時立即停止，不啟動模型。

### 關卡 B：五句文字快速測試（不修圖）

1. 從已知日文取五句：對話、旁白、數字／單位、擬聲詞、長句各一。
2. 只載入翻譯模型，不跑文字偵測、OCR、補背景或排字。
3. 每句必須獨立翻譯，禁止用一個回答包含多個文字區塊。
4. 結果必須是非空白繁體中文，不得回吐提示詞、原文或解釋。
5. 維持一份「已通過翻譯模型／參數」基準，之後直接沿用。

失敗條件：五句中任一句空白、錯位、提示詞回吐或明顯誤譯。同一模型最多修正一次；再失敗就淘汰，禁止反覆重跑圖片流程。

### 關卡 C：三頁視覺校正

1. 固定抽取前、中、後各一頁，選有旁白、對話、擬聲詞或複雜背景的頁面。
2. 檢查 OCR 原文與翻譯對照，確認沒有順序錯位。
3. 檢查日文是否清除、背景是否可接受、中文是否貼合原文區域。
4. 維持「去除日文、只留繁中、字框不過度放大」的固定排版規則。
5. 三頁結果供人工確認；未通過前禁止整本執行。

### 關卡 D：整本執行與封裝

1. 一次一頁，禁止並行批次，以降低 16 GB RAM 環境的中斷風險。
2. 每頁完成後立即寫入狀態：頁碼、原圖名、輸出名、OCR 區塊數、翻譯區塊數、成功／失敗原因。
3. 中斷後只續跑未完成頁，不重跑已驗證頁面。
4. 單頁最多嘗試三次；任一頁最終失敗，整本不封裝。
5. 封裝前檢查：頁數相等、順序相等、每張圖可解碼、沒有 0-byte 檔案、沒有多餘檔案。
6. 在暫存名稱下建立 ZIP，再重新開啟驗證壓縮檔。
7. 驗證通過後，才原子更名為最終同名 ZIP。

## 4. 清理規則

### 成功時

1. 確認最終 ZIP 可重新開啟，且內含頁數與原作相同。
2. 確認 ZIP 內只有翻譯圖片。
3. 刪除該任務的解壓原圖副本、校正圖、翻譯暫存圖、中間遮罩、局部記錄與任務資料夾。
4. 保留共用的 Python 環境、模型、快取與 SOP，避免下次重新下載。
5. 保留來源日文 ZIP。

### 失敗或中斷時

- 不建立或不更名為最終 ZIP。
- 保留最少可續作狀態與已完成頁，避免全部重跑。
- 使用者取消專案時，需再確認後清除該任務工作區；不得刪除原始 ZIP 或共用模型。

## 5. 效率與迭代規則

- 新模型必須先過五句關卡，不得直接跑圖片。
- 翻譯、OCR、去字、排版分開記錄，不因單一環節失敗而重跑全部。
- 每次只改一個主要變數，例如模型、提示、遮罩或字體大小，才能比較效果。
- 保留「當前最佳設定」與最後三頁比較結果，新方案沒有更好就回到基準。
- 不讀取與當前關卡無關的原始碼、模型或漫畫頁面。
- 紀錄每頁耗時，整本預估時間用已完成頁面的中位數計算，不用猜測。

## 6. 本機目前基準

- GPU：NVIDIA GeForce RTX 5060，8 GB VRAM。
- RAM：16 GB；固定單頁、單批次，禁止並行。
- NLLB 600M：技術上可運行，日文直轉繁中品質不合格，不得當作整本基準。
- Qwen2 1.5B：已下載，仍需通過五句單句測試。
- 備用方案：Sugoi 日文→英文，再用 NLLB 英文→繁中。仍必須先通過五句關卡。

## 7. 不可跳過的停止條件

- 五句翻譯沒有全部通過。
- 三頁校正尚未經使用者確認。
- 任一頁翻譯失敗或輸出圖無法解碼。
- 輸出頁數或順序與原始 ZIP 不一致。
- 最終 ZIP 內出現非翻譯圖片的任何檔案。
