# 漫畫下載助手（Edge 2.0 配套版）

點開擴充功能後，會把目前的 WNACG、18comic 或 nhentai 漫畫交給既有的網頁下載功能；檢查、重複、失敗與下載進度都顯示在原本漫畫書庫。

## 安裝到 Edge

1. 從每日工作台開啟漫畫整理程式，或執行主機版的「啟動漫畫網頁版.bat」。
2. 在 Edge 網址列輸入 edge://extensions。
3. 開啟左側的「開發人員模式」。
4. 按「載入解壓縮的擴充功能」。
5. 選擇主機版內的整個 `edge-extension` 資料夾。不要選擇 E 槽攜帶版的擴充功能資料夾。
6. 將「漫畫下載助手（Edge 測試版）」固定在工具列。

修改擴充功能檔案後，需在 `edge://extensions` 按一次「重新載入」，並重新整理已開啟的漫畫書庫頁面，不必重開 Edge。主機版目前要求擴充功能版本 `0.7.2` 以上。

若要在 InPrivate 使用，請在擴充功能的「詳細資料」開啟「允許 InPrivate」。

## 使用方式

1. 啟動主機版漫畫書庫，並在 Edge 開啟支援的漫畫目錄頁。
2. 第一次點擴充功能時，從既有漫畫書庫位置中選擇下載位置，再按「設定並下載」。
3. 之後在漫畫頁點擴充功能就會直接送出，不再詢問。
4. 擴充功能會在背景使用原本的批次下載視窗，不會強制切換頁面；需要時可自行到漫畫書庫查看檢查與下載進度。
5. 可以切換到其他漫畫分頁重複操作，短時間內加入多部。

若要更換下載位置，先切到漫畫書庫頁再開啟擴充功能，即可只儲存新位置而不新增下載。InPrivate 與一般視窗的擴充資料分開，第一次使用時需各設定一次。

## 從網頁或文件批次加入

漫畫書庫網頁可直接貼入一個或多個網址，也可使用「讀取文件」。WNACG 由本機程式直接讀取；18comic 與 nhentai 會透過這個 Edge 助手取得瀏覽器中的作品資料，再回到同一個下載佇列。

## 第一版限制

- 接受 wnacg.com、wnacg.ru、18comic.vip 與 nhentai.net 的目錄／閱讀網址。
- 加入後會直接檢查並下載，不再要求人工確認。
- 重複漫畫會在原本下載視窗顯示並暫停，不會直接覆蓋。
- 支援短時間加入多部，原本下載視窗會分別顯示各工作的狀態。
- 本機漫畫書庫必須正在執行，預設網址為 http://127.0.0.1:8765/。
- 藍色角標代表目前尚未完成的部數；紅色驚嘆號代表發生錯誤。
- 18comic 會短暫開啟前景分頁取得登入狀態下的作品資料，讓延遲載入圖片完整出現；讀取完成後自動關閉。若作品標示 101 頁，必須實際讀滿 101 頁才會送入下載。
- nhentai 會從目錄頁讀取英文標籤與語言，並從閱讀頁取得高畫質圖片；不會使用目錄縮圖。

主機版與攜帶版的 Edge 助手應分開載入；本機日常使用只載入主機版資料夾。
