# 漫畫壓縮檔管理器（本機網頁版 2.0）

這是一個只在 Windows 本機執行的 ZIP／CBZ 書庫、閱讀與排序工具。畫面由瀏覽器呈現，但漫畫內容不會上傳，也不需要任何雲端服務。

## 啟動

平常請直接雙擊 `重新啟動漫畫網頁版.bat`。它會確認書庫與下載橋接的狀態，必要時重新啟動，成功後自動開啟瀏覽器。舊的 `啟動漫畫網頁版.bat` 會轉交給同一套新流程，因此原本的捷徑仍可繼續使用。

需要手動除錯時，也可以在本資料夾開啟 PowerShell，執行：

```powershell
python main.py
```

程式會同時啟動書庫服務 `http://127.0.0.1:8765/` 與下載橋接服務 `http://127.0.0.1:8766/`。平常只需開啟 8765 的書庫網址；每日工作台也會從這個主機資料夾啟動兩項服務。

為避免大量圖片請求讓記錄檔無限制增長，平常不記錄每一筆 HTTP 存取；需要除錯時可先設定環境變數 `COMIC_WEB_ACCESS_LOG=1` 再啟動。

本機正式資料位於本資料夾的 `data`。`E:\漫畫網頁版_MVP` 是外出使用的攜帶版，主機版不得讀取或啟動該處的程式與資料；書庫中原本設定的漫畫收藏路徑不受這項限制。

打包後的 Windows 攜帶版可直接從隨身硬碟執行，不需要另外安裝 Python。攜帶版會把資料庫放在執行檔旁的 `data` 資料夾，啟動時自動開啟瀏覽器；如果 Windows 更換了隨身硬碟代號，程式會自動調整同一顆硬碟內的漫畫路徑。

## 已完成範圍

- 新增一個或多個本機掃描資料夾，遞迴索引 ZIP／CBZ。
- SQLite 虛擬書庫、模糊搜尋、作者與單一自訂分組。
- 封面卡片、實際路徑、頁數與檔案大小。
- 「開始閱讀」會在獨立分頁開啟純閱讀器，也可使用右鍵或滑鼠中鍵開啟；每次從第一頁開始，不保存頁碼。
- 獨立閱讀器提供左右方向鍵、頁碼、圖片名稱、縮圖總覽與放大，不提供任何漫畫修改功能。
- 左下角「設定」可選擇開始閱讀時預設使用目前頁面或新分頁；「開始閱讀」旁的 ▼ 可單次改用另一種方式，不改變預設值。
- 書庫工具列提供平常隱藏的「多選」模式；啟用後才顯示漫畫卡片選取框與批次操作。漫畫卡片封面不放頁數或格式，ZIP／CBZ 格式標示位於卡片內容右下角；詳細資訊中的頁數位於「集數」下方。
- 從當前頁進入拖曳排序；暫存排序、內部圖片改名與刪除。
- 寫入前顯示變更摘要並要求輸入確認文字。
- 同目錄建立暫存 ZIP、逐圖驗證後才替換正式檔；失敗會還原原檔。
- 壓縮檔重新命名、移動會要求輸入完整檔名確認；永久刪除會顯示完整檔名與路徑並要求再次按下確認。
- 重複檢查分成「檔案完全相同」與「疑似內容相同」：前者以 SHA-256 快速確認位元完全相同，後者不以檔案大小、檔名或路徑判斷，會比較壓縮檔內的頁數與圖片視覺特徵；結果只提示，不自動刪除。
- 可在書庫網頁貼上一個或多個網址，或從文字文件讀取網址。WNACG 由本機程式直接處理；18comic 與 nhentai 需要安裝本資料夾內的 Edge 下載助手，由瀏覽器取得作品與高畫質圖片資料。
- 也可在 WNACG、18comic 或 nhentai 作品頁直接點 Edge 下載助手，把目前作品送進同一個下載佇列。
- 更新 Edge 下載助手後，需在 `edge://extensions` 對「漫畫下載助手」按一次「重新載入」，再重新整理已開啟的漫畫書庫頁面。
- 網頁下載會先檢查來源、同名檔案及既有下載紀錄，再送出可下載項目。整本下載會安全排隊並分別顯示進度。
- 網頁下載每頁最多重試 3 次、單次連線逾時 20 秒、整批上限 10 分鐘；任一頁缺失、損壞或超時時取消整批並顯示失敗頁碼，不留下正式 ZIP。
- 網頁下載完成前會驗證圖片數量、檔名順序與 ZIP 完整性，成功後才加入所選書庫資料夾。
- 網頁下載佇列會保存於本機資料夾；重新啟動後，未完成項目會標記為失敗並清除半成品，提供從頭重新下載，已完成項目與後續等待項目都會保留。

## 資料安全

- 掃描、搜尋、閱讀、作者與分組設定都不會改動漫畫檔案。
- 只有使用者主動確認重新命名、移動、刪除或「套用並覆蓋」時才寫入。
- 套用內部編輯不會直接原地修改 ZIP；新檔完整驗證成功後才替換。
- 程式升級前只保留必要的壓縮備份，不複製漫畫收藏。重要收藏仍由使用者自行另行備份。
